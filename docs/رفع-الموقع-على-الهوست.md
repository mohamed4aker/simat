# رفع موقع سِمة على الهوست (cPanel) + قاعدة البيانات

هتحتاج 3 ملفات:
- **simat-cpanel.zip** ← الموقع نفسه
- **schema.sql** و **seed.sql** ← جداول قاعدة البيانات والـ 58 عطر

(لو ضاعوا: الموقع بيطلع بالأمر `npm run package:cpanel` من فولدر `web`، والملفين
في `web/supabase/`.)

> الترتيب مهم: **قاعدة البيانات الأول ← بعدين الموقع ← بعدين حساب الأدمن.**

---

## ١. قاعدة البيانات (Supabase)

1. ادخل مشروعك على supabase.com.
2. من القايمة اللي على الشمال افتح **SQL Editor** ← **New query**.
3. افتح ملف **schema.sql** على اللاب (بالـ Notepad)، انسخ كل اللي فيه (Ctrl+A ثم Ctrl+C)،
   والزقه في Supabase، ودوس **Run**. لازم يطلع **Success**.
4. اعمل **New query** تاني، وكرر نفس الكلام مع ملف **seed.sql** ← **Run** ← **Success**.
5. هات المفاتيح: **Project Settings** (الترس تحت على الشمال) ← **API** (أو **API Keys**)،
   وخلي الصفحة دي مفتوحة — هتنسخ منها 3 حاجات في الخطوة ٣:
   - **Project URL** — شكله `https://xxxx.supabase.co`
   - **anon public** key
   - **service_role** key ← ⚠️ ده سري جداً: ماتبعتهوش لحد ولا تحطه غير في الهوست.

## ٢. ارفع الموقع

1. ادخل الـ cPanel ← **File Manager**.
2. هتفتح على الفولدر الرئيسي — **متدخلش جوه public_html**.
3. دوس **+ Folder** ← اكتب `simat` ← **Create New Folder**.
   (لو الفولدر موجود من نسخة قديمة: ادخله وامسح كل اللي جواه الأول.)
4. ادخل جوه فولدر `simat` ← **Upload** ← اختار **simat-cpanel.zip** ← استنى لحد 100%.
5. ارجع، كليك يمين على الملف ← **Extract** ← **Extract Files**.
6. امسح ملف الـ zip بعد ما يتفك.

## ٣. شغّل الموقع وحط المفاتيح

1. افتح **Setup Node.js App** ← **Create Application** (أو ✏️ لو موجود قبل كده).
2. املى الخانات:

| الخانة | تكتب فيها |
|---|---|
| Node.js version | **22** (ولو مش موجود **20**) |
| Application mode | **Production** |
| Application root | `simat` |
| Application URL | `simatfragrances.com` |
| Application startup file | `server.js` |

3. تحت عند **Environment variables** دوس **Add Variable** وضيف دول واحد واحد:

| Name | Value |
|---|---|
| `SUPABASE_URL` | الـ Project URL |
| `SUPABASE_ANON_KEY` | الـ anon public key |
| `SUPABASE_SERVICE_ROLE_KEY` | الـ service_role key |

4. دوس **Create** (أو **Save**) وبعدين **Restart**.
5. **متدوسش Run NPM Install.**

## ٤. القفل 🔒 (https)

cPanel ← **SSL/TLS Status** ← علّم على `simatfragrances.com` و `www.simatfragrances.com`
← **Run AutoSSL**. استنى كام دقيقة.

## ٥. افتح الموقع

**https://simatfragrances.com** — لازم تلاقي العطور بصورها وأسعارها.

## ٦. حساب الأدمن (لوحة التحكم)

1. Supabase ← **Authentication** ← **Users** ← **Add user** ← **Create new user**
   ← اكتب إيميل العميل وباسورد ← علّم على **Auto Confirm User** ← **Create user**.
2. Supabase ← **SQL Editor** ← **New query** ← الزق السطر ده بعد ما تغيّر الإيميل والاسم ← **Run**:

```sql
insert into public.admin_users (email, name)
values ('emailclient@example.com', 'اسم العميل');
```

3. افتح **https://simatfragrances.com/admin** وادخل بالإيميل والباسورد.

تقدر تعمل أكتر من أدمن (كرر الخطوات بإيميل تاني). وأي حد إيميله مش في الجدول ده
مش هيقدر يشوف ولا طلب حتى لو عرف اللينك.

### اللي في لوحة التحكم

- **المنتجات:** إضافة وتعديل العطور والأسعار والأحجام والمخزون والوصف، ورفع الصور
  من الموبايل أو اللاب على طول (زرار «ارفع صورة»).
- **الطلبات:** متابعة الطلبات وتغيير حالتها.
- **تصميم الموقع:** السلايدر (صور وبانرات ولينكات)، صور وأسامي الفئات، شريط الإعلان،
  قصتنا، الأسئلة الشائعة، «زورنا في المحل»، بيانات التواصل والسوشيال، وأسعار الشحن لكل
  محافظة وحد الشحن المجاني. بعد «احفظ التعديلات» بتظهر على الموقع على طول.

> زرار «ارفع صورة» محتاج فولدر الصور في Supabase — بيتعمل لوحده لما تشغّل
> `schema.sql` أو ملف `update-db.sql`.

## اتأكد إن كله شغال

- اعمل طلب تجربة من الموقع ← لازم يظهر رقم طلب.
- ادخل **/admin** ← لازم تلاقي الطلب في **الطلبات**.
- لو صفحة الأدمن قالتلك «لازم نربط Supabase»: المفاتيح مش متحطة صح — راجع الخطوة ٣
  واعمل **Restart**.

## لو ظهرت مشكلة

- افتح فولدر `simat` في File Manager ودوّر على ملف **stderr.log** — فيه سبب المشكلة.
- جرّب **Restart** من **Setup Node.js App**.
- لو الصفحة فاضية أو 503: اتأكد إن Application root مكتوب `simat` بالظبط، وإن
  `server.js` موجود جوه فولدر `simat` مباشرة (مش جوه فولدر تاني).
- لو الدومين مش بيفتح خالص: الدومين محتاج يكون موجّه على الهوست (A record على IP
  السيرفر `5.39.102.68`).
