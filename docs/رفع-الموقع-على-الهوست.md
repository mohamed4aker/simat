# رفع موقع سِمة على الهوست (cPanel)

الملف اللي هترفعه: **simat-cpanel.zip**
(لو ضاع منك، أي مبرمج يقدر يطلعه تاني بالأمر ده من فولدر `web`:
`npm run package:cpanel` — وهيطلع في `web/dist/simat-cpanel.zip`)

---

## ١. اعمل رابط للموقع

1. ادخل الـ cPanel.
2. افتح **Domains**.
3. دوس **Create A New Domain**.
4. اكتب: `simat.businessplus-eg.com`
5. دوس **Submit**.

## ٢. ارفع الملف

1. افتح **File Manager**.
2. هتفتح على الفولدر الرئيسي — **متدخلش جوه public_html**.
3. دوس **+ Folder** ← اكتب `simat` ← **Create New Folder**.
4. ادخل جوه فولدر `simat`.
5. دوس **Upload** ← اختار **simat-cpanel.zip** ← استنى لحد 100%.
6. كليك يمين على الملف ← **Extract** ← **Extract Files**.
7. امسح ملف الـ zip (كليك يمين ← **Delete**).

## ٣. شغّل الموقع

1. افتح **Setup Node.js App**.
2. دوس **Create Application**.
3. املى الخانات:

| الخانة | تكتب فيها |
|---|---|
| Node.js version | **22** (ولو مش موجود **20**) |
| Application mode | **Production** |
| Application root | `simat` |
| Application URL | `simat.businessplus-eg.com` |
| Application startup file | `server.js` |

4. دوس **Create**.
5. **متدوسش Run NPM Install.**

## ٤. افتح الموقع

**https://simat.businessplus-eg.com**
(القفل 🔒 ممكن ياخد كام دقيقة يظهر)

---

## لو ظهرت مشكلة

- افتح فولدر `simat` في File Manager ودوّر على ملف **stderr.log** — فيه سبب المشكلة.
- جرّب من **Setup Node.js App** تدوس **Restart** على التطبيق.
- لو الصفحة فاضية أو 503: اتأكد إن Application root مكتوب `simat` بالظبط، وإن ملف
  `server.js` موجود جوه فولدر `simat` مباشرة (مش جوه فولدر تاني).

## ملحوظات

- الطلبات مش هتتحفظ غير لما قاعدة البيانات (Supabase) تتربط — الخطوات في `web/README.md`.
- لما العميل يشتري دومين خاص بيه: يتضاف من **Domains** بنفس الطريقة، ويتغيّر
  Application URL للدومين الجديد، وتتعمل نسخة جديدة من الملف برابط الدومين.
