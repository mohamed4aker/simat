# رسالة واتساب تلقائية بعد كل طلب

بعد أي طلب (من الموقع أو الأبلكيشن) بيوصل للعميل على واتساب من رقم سِمة
**+20 12 73162855** رسالة فيها تفاصيل الطلب وزرارين:

- **تأكيد الطلب** ← الطلب بيتحول لـ «تم التأكيد» في لوحة التحكم لوحده.
- **إلغاء** ← الطلب بيتحول لـ «ملغي».

الكود جاهز ومجرّب. فاضل تفعيله من حساب Meta بالخطوات دي.

---

## ١. اللي محتاجينه قبل ما نبدأ

- حساب **Meta Business** (business.facebook.com) باسم سِمة.
- رقم سِمة يتنقل لـ **WhatsApp Business Platform (API)**.

> ⚠ مهم: الرقم لو شغال دلوقتي على أبلكيشن **WhatsApp Business** على الموبايل،
> نقله للـ API بيوقف استخدامه من الأبلكيشن العادي — إلا لو اتعمل بخاصية
> **Coexistence** (استخدام الأبلكيشن والـ API على نفس الرقم) من خلال Meta أو
> شركة وسيطة بتدعمها. القرار ده لازم يتاخد قبل الربط.

- Meta بتاخد رسوم صغيرة على كل رسالة «Utility» (رسايل الطلبات)، والأسعار
  الحالية لمصر موجودة في صفحة أسعار WhatsApp Business من Meta.

## ٢. تسجيل القالب (Template)

من **WhatsApp Manager → Message templates → Create template**:

- **Category:** Utility
- **Name:** `order_confirmation`
- **Language:** Arabic
- **Body:**

```
أهلاً {{1}} 👋
تم استلام طلبك من سِمة بنجاح ✅

رقم الطلب: {{2}}
المنتجات: {{3}}
مبلغ التحصيل: {{4}} جنيه
العنوان: {{5}}

برجاء تأكيد الطلب عشان نجهزه ونشحنه.
```

- **Buttons → Quick reply:** زرار أول `تأكيد الطلب` وزرار تاني `إلغاء`
  (بنفس الترتيب ده).

استنى لحد ما القالب ياخد **Approved**.

## ٣. متغيرات البيئة على السيرفر

| المتغير | منين |
|---|---|
| `WHATSAPP_TOKEN` | Business Settings → System users → توكن دائم بصلاحية `whatsapp_business_messaging` |
| `WHATSAPP_PHONE_NUMBER_ID` | WhatsApp Manager → Phone numbers → Phone number ID |
| `WHATSAPP_APP_SECRET` | developers.facebook.com → التطبيق → App settings → Basic → App secret |
| `WHATSAPP_VERIFY_TOKEN` | أي كلمة سر تختارها (هتكتبها تاني في خطوة ٤) |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase → Project Settings → API → service_role (سرّي) |
| `WHATSAPP_TEMPLATE` | اختياري — الافتراضي `order_confirmation` |
| `WHATSAPP_TEMPLATE_LANG` | اختياري — الافتراضي `ar` |

- **على Vercel:** Settings → Environment Variables، وبعدها Redeploy.
- **على الـ cPanel:** Setup Node.js App → التطبيق → Environment variables → Add، وبعدها Restart.

> متحطش أي واحد من دول في الكود أو في متغير يبدأ بـ `NEXT_PUBLIC_`.

## ٤. ربط الـ Webhook (عشان زرار التأكيد يشتغل)

developers.facebook.com → التطبيق → WhatsApp → Configuration → Webhook:

- **Callback URL:** `https://<الدومين>/api/whatsapp/webhook`
- **Verify token:** نفس قيمة `WHATSAPP_VERIFY_TOKEN`
- **Webhook fields:** فعّل `messages`

## ٥. التجربة

اعمل طلب تجريبي برقمك من الموقع ← هتوصلك الرسالة ← دوس «تأكيد الطلب» ←
افتح لوحة التحكم هتلاقي الطلب بقى «تم التأكيد»، ومكتوب في سجله «العميل أكد
الطلب من واتساب».

### ملاحظات

- الرسالة بتتبعت بس لما قاعدة البيانات (Supabase) تكون متوصلة — في وضع العرض
  الطلبات مش بتتسجل فمفيش رسايل.
- التأكيد مقبول بس من نفس رقم العميل اللي عمل الطلب، وبس لو الطلب لسه
  «قيد المراجعة».
- لو الإرسال فشل لأي سبب، الطلب بيتسجل عادي والخطأ بيظهر في سجل السيرفر.
