# SIMAT — سِمة | متجر العطور

<div dir="rtl">

مشروع **متجر إلكتروني (E-commerce)** كامل لعلامة العطور **سِمة — SIMAT**:
تطبيق موبايل للعملاء + لوحة تحكم للأدمن جوّه نفس التطبيق، وبعدين موقع ويب
يشارك نفس الهوية ونفس الباك إند.

---

## المصطلح: ده اسمه إيه؟

اللي إنت طالبه اسمه **تجارة إلكترونية — E-commerce**، وبالتحديد نوع
**D2C / Single-vendor store** (متجر لعلامة واحدة بيبيع للمستهلك مباشرة).
مش «ماركت بليس» — الماركت بليس بيبقى فيه بائعين كتير زي أمازون ونون.

المشروع بيتكوّن من ٣ أجزاء:

| الجزء | الاسم التقني | الحالة |
|---|---|---|
| تطبيق العميل | Customer App (Android + iOS) | ✅ متعمل هنا |
| لوحة الإدارة | Admin Dashboard / Back-office | ✅ متعملة جوّه نفس التطبيق |
| الموقع | Storefront Web (نفس الـ API) | 🔜 المرحلة الجاية |

---

## ليه Flutter؟

طلبك: **أندرويد + iOS**. الاختيار المنطقي هو **Flutter**:

- **كود واحد** يطلع تطبيق أندرويد وتطبيق آيفون + ويب من نفس المصدر.
- أداء أصلي (بيتترجم لكود native) والواجهة بترسم بنفسها، فالشكل بيبقى
  **مطابق ١٠٠٪** على الجهازين — مهم جداً لعلامة عطور فخمة.
- دعم عربي/RTL ممتاز وخطوط مخصّصة من غير مشاكل.
- سرعة تطوير أعلى وتكلفة أقل من إننا نعمل تطبيقين منفصلين
  (Kotlin + Swift).

البدائل زي React Native كويسة برضه، بس Flutter أدق في التحكم في التفاصيل
البصرية، وده اللي محتاجينه عشان الهوية تطلع زي التصميم بالظبط.

## اللي اتعمل في التطبيق

### واجهة العميل
- **الرئيسية**: بانر بهوية سِمة، تصنيفات، مختارات، عروض، الأكثر مبيعاً،
  وصل حديثاً، قصة العلامة.
- **المتجر**: شبكة منتجات + فلترة (تصنيف، فئة، تركيز، سعر، متوفر، عروض)
  + ترتيب (الأحدث / الأرخص / الأغلى / الأعلى تقييماً / الأكثر مبيعاً).
- **البحث**: بحث فوري بالاسم أو الماركة أو **النوتة العطرية**، مع تطبيع
  الحروف العربية (الهمزات والتاء المربوطة والألف المقصورة).
- **صفحة المنتج**: الهرم العطري (نوتات عليا/قلب/قاعدة)، الثبات، الحجم،
  التركيز، حالة المخزون، التقييمات، منتجات مشابهة.
- **العربة**: تعديل الكميات، حذف بالسحب، مؤشّر الشحن المجاني.
- **إتمام الطلب**: اختيار/إضافة عنوان، طريقة الدفع، كوبون خصم، ملاحظات،
  حساب الشحن حسب المحافظة، وملخّص نهائي.
- **الطلبات**: قائمة الطلبات + شاشة تتبّع بخط زمني للحالات + إلغاء الطلب.
- **الحساب**: المفضلة، العناوين، تعديل البيانات، تغيير كلمة السر.

### لوحة تحكم الأدمن
- **اللوحة**: مبيعات الفترة ونسبة النمو، عدد الطلبات، متوسط قيمة الطلب،
  القطع المباعة، **منحنى مبيعات**، توزيع حالات الطلبات، الأكثر مبيعاً،
  مخزون على وشك النفاد، أحدث الطلبات.
- **التقارير**: فلترة بالفترة (اليوم/أسبوع/شهر/٣ شهور/سنة/الكل)، مبيعات
  حسب التصنيف، الإيراد حسب طريقة الدفع، أفضل ١٠ منتجات، أفضل العملاء،
  و**تصدير الطلبات CSV**.
- **المنتجات**: إضافة/تعديل/حذف، تفعيل وإيقاف، بحث وتبويبات (مفعّل /
  موقوف / مخزون منخفض).
- **الطلبات**: بحث وفلترة بالحالة، وتغيير حالة الطلب بضغطة، مع سجل كامل
  لكل تغيير.
- **العملاء**: إحصائيات كل عميل (عدد الطلبات، إجمالي الشراء) وإيقاف حساب.
- **التصنيفات والكوبونات**: إدارة كاملة.

## التشغيل

```bash
cd app
flutter pub get

# أندرويد أو آيفون (جهاز أو محاكي)
flutter run

# بناء نسخة للنشر
flutter build apk --release          # أندرويد
flutter build appbundle --release    # Google Play
flutter build ipa --release          # آيفون (محتاج macOS + Xcode)
```

### حسابات التجربة

| الدور | الموبايل | كلمة السر |
|---|---|---|
| أدمن | `01000000000` | `admin123` |
| عميل | `01011112222` | `123456` |

٦ شهور، عشان التقارير تبقى شغّالة من أول تشغيل.

## البيانات دلوقتي مخزّنة فين؟

الربط بالباك إند بيغيّر **طبقة الـ Repositories بس** — الواجهات كلها
تفضل زي ما هي. التفاصيل في [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
وخطة الربط في [`docs/ROADMAP.md`](docs/ROADMAP.md).
